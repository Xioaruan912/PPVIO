# PPVIO Curation Implementation Plan

> **For agentic workers:** Follow isolated ownership below. Independent modules use dispatching-parallel-agents; parent owns shared assembly and range playback.

**Goal:** Implement the three prioritized adult-private-library improvements using existing metadata and video playback.
**Architecture:** Extend persistent tags/curation/preferences and compatible encrypted backup; deterministic preferred feed; optional bookmark ranges rendered by the native feed.
**Tech Stack:** Python/aiohttp/SQLite, React/TypeScript/Vitest; no dependencies.
**Spec:** docs/superpowers/specs/2026-11-03-curation-design.md

## Global Constraints

- No TGVIO access, external matching, media upload/move; preserve opaque IDs/auth/same-origin.
- Append migration0022; old manifests1–3 readable; schema4 adds curation and optional bookmark end_seconds; encryption contexts unchanged.
- Preference lists max20 IDs each, disjoint, mode mixed/only; only requires preferred tags. Batch max100 media,20 add/remove tags each.
- Independent work must not mutate shared server/sqlite/main/api.ts/App/Feed assembly until parent integrates.
- TDD for meaningful behavior; full scripts/check.sh before commits; only clean pushed main release.py deploy.

## Review Focus

- Feed exclusions and stale queues/requests across preference/tag changes.
- Restore before catalog scan, tag ID/name conflicts, dirty snapshots and storage update races.
- Atomic batch validation, rendition/deleted-media exclusion and pagination after updates.
- Multiple ranges of the same source, duration clamping and stale playback/seek callbacks.
- Privacy/background/pause during loops and preloading; real browser range playback.
